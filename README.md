# Umaira Sadaf | Creative Portfolio with Working Contact Form

## Assignment: Make It Do Something

### What This Feature Does
This is a **working contact form** built into a creative portfolio website. When someone visits the site and fills out the contact form, their message is sent to my email inbox.

### Why It Matters
A static portfolio tells people who you are. A portfolio with a **working contact feature** actually lets people *reach you*. This is the difference between a poster (looks nice) and a tool (actually works). This contact form is genuinely functional—real inquiries would land in my inbox.

---

## How It Works (Plain Words)

### The Data Flow:
1. **User visits** the portfolio website
2. **User fills** in the contact form (name, email, message)
3. **User clicks** "Send Message"
4. **Form data goes** to Formspree (a free form-handling service)
5. **Email arrives** in my inbox at humerasadaf59@gmail.com
6. **Success message** appears to confirm the user their message was sent

### The Backend:
- **Frontend**: HTML, CSS, and JavaScript (no server needed)
- **Form Handler**: Formspree.io (free service that accepts form submissions and emails them)
- **Hosting**: GitHub + Netlify (free deployment)

### Why This Works:
- No database to maintain
- No server code to write
- Uses free services only
- Actually functional—not a mock or demo
- Real submissions would genuinely reach me

## How to Use This

1. Open `index.html` in your browser
2. Fill out the form and submit

### Deploy to Netlify:
1. Push this repo to GitHub
2. Go to netlify.com and log in
3. Click "New site from Git"
4. Select your GitHub repo
5. Deploy! (takes 30 seconds)
